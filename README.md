# BuildIT
BuildIT repositories

Game Description

PC Build Academy is a 2D interactive educational mobile game designed to teach beginners the basics of assembling a computer system. Players learn to identify computer components, understand their functions, and assemble them in the correct order through a guided and interactive simulation.

Game Objective

The main objective of the game is to provide a safe, accessible, and engaging way for beginners to learn computer assembly without the risk of damaging real hardware. Players will practice installing components, connecting cables, identifying common mistakes, and completing a successful computer build.
